FOLDER MUSIK
============

Letakkan file lagu di sini dengan nama PERSIS seperti ini:

  space-song.mp3     -> untuk pilihan "Space Song" (Beach House)
  ruang-rindu.mp3    -> untuk pilihan "Ruang Rindu" (Letto)

Catatan:
- Aku tidak bisa ikut menyertakan lagunya karena berhak cipta, jadi kamu
  yang menaruh file mp3-nya sendiri (mis. hasil unduhan legal kamu).
- Kalau file belum ada, tombol lagu itu otomatis memutar musik "Ambient"
  bawaan situs supaya tetap ada suara.
- Format yang paling aman: .mp3 (bisa juga .m4a/.ogg, tinggal samakan
  namanya dan ubah path di js/main.js bagian SONGS).
